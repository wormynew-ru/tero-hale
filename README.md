# Hero Tale — 2D Idle RPG (Godot 4.7)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Godot Engine](https://img.shields.io/badge/Godot-4.7-478cbf.svg)](https://godotengine.org/)
[![Version](https://img.shields.io/badge/Version-0.26.0-purple.svg)](godot_project/CHANGELOG.md)

Кроссплатформенная 2D Idle RPG в духе **Hero Tale**, созданная на **Godot Engine 4.7** (`GL Compatibility`) с адаптивным горизонтальным интерфейсом (`1280×720`, `canvas_items` + `expand`, широкие мобильные скроллбары `mobile_theme.tres`) для **ПК и смартфонов**.

В репозитории также включён веб-инспектор исходного кода на **React + TypeScript + Vite** для просмотра дерева файлов, сцен, скриптов и `.tres`-ресурсов прямо в браузере, а также набор автотестов целостности проекта.

---

## Ключевые особенности и механики

### Бой, честный AFK-режим и управление
- **Честный автобой в реальном времени и Параллельные бои (`x1 / x3 / x5 / x10`)**: никакой офлайн-прогрессии и ускорения атак кликами (`⚔️`/`🏳️` — только переключатель поиска боя), **параллельные бои до 10 врагов сразу** (с переносом избыточного одиночного урона и AoE по всей пачке), а также опция **⏩ Авто-Сл** для бесшовного перехода на `N+1` после победы над Вечным титаном; симуляция продолжает работать в свёрнутом или неактивном окне (`PROCESS_MODE_ALWAYS`, `low_processor_mode=false`).
- **Облегчённый `🌙 AFK-режим` с выбором FPS (`15 / 20 / 30 / 60`)**: скрывает основной UI (`RootHBox`), пропускает обновления полос арены и кнопок заклинаний, удерживает экран активным (`DisplayServer.screen_set_keep_on(true)`) и позволяет снизить лимит FPS до `15`, `20` (по умолчанию) или `30` для экономии батареи.
- **Оптимизация под мобильные устройства**: троттлинг перерисовки `AttackDiamond` (20 Гц), ленивое кэширование расчётных статов (`_stats_cache_dirty`), пулы строк и карточек без `queue_free()`, пауза арены при открытом меню, асинхронное атомарное сохранение в потоке `Thread` с бэкапом (`user://save.bak.tres`), O(1)-кэши ресурсов и автоклик **50 нажатий/с** при удержании кнопок.

### Прокачка, статы и *Learn by Doing*
- **4 базовые характеристики**: Сила, Ловкость, Выносливость и **прокачиваемая Инта** (`base_intellect` качается за ОН и золото кнопками **`+1 / +10 / +25 / +50 / Макс`** и автокликом `50/с`, отображается отдельным кругом на арене).
- **Усиленное масштабирование выживаемости и маны**: `+60 Max HP` за Выносливость (`4x`), `+16 Max MP` за Выносливость и `+32 Max MP` за Инту (`8x`).
- **3 навыка практики (*Learn by Doing*)**:
  - **⚔️ Ближний бой** — опыт за удары оружием ближнего боя (`+3%` урона/ур.).
  - **🏹 Дальний бой** — опыт за выстрелы из лука/арбалета со снарядом (`+3.5%` урона и `+0.3%` крита/ур.).
  - **✨ Магия** — опыт равен затраченной мане заклинаний и выстрелам из посоха (`+3.5%` силы чар и `+4%` регена маны/ур.).

- **6 постоянных Тёмных Мастерств (`🥋 Полигон тренировок`)**: прокачиваются в специальной локации **Полигон тренировок** (выбираются во вкладке `Статы` и **не сбрасываются между ранами**): Тёмный ближний бой, Тёмный дальний бой, Тёмная магия, Тёмное отражение, Тёмная устойчивость (`+6%` брони и `+5%` Барьера/ур.) и Тёмный закал (`+5%` Max HP/ур.).

### Снаряжение, Вторая рука, магия, кузня и настраиваемые авто-зелья
- **101 предмет, Вторая рука с +Отражением, усиленный Барьер и защита от оружия**: мечи/клинки, луки и арбалеты со стрелами/болтами (`x50`), магические посохи, мантии, **щиты и талисманы Второй руки (усиленный `🛡️ Барьер` с регенерацией в бою/за убийство и `+Отражение` на каждом оффхенде)**, книги-снаряды двух типов и `⏳ Сфера Сброса Сумрака`. Выпавшая экипировка получает случайное **Качество (`80%–125%`)**, сливается в Кузне (`★1–★5`) и при необходимости разбирается **Авто-разбором** в золото и **🔹 Осколки Бездны**.
- **Дроп-экономика**: базовая экипировка и весь стартовый арсенал покупаются в лавке, а высокоуровневые клинки, редкая броня, топовые посохи/мантии и редкие щиты/талисманы выбиваются только с врагов, боссов и сундуков.
- **Книга заклинаний (27 чар × Ур.1–5 × 2 Руны A/B, 3 активных слота)**: заклинания качаются от кастов или за `📜 Древние листы`, а каждое из 27 заклинаний имеет 2 уникальные руны (`A`/`B`). Короткий тап — каст, удержание `1 сек` — автокаст.
- **Кузня и 🔥 Тёмная кузня**: обычная заточка за золото до `+100` (`+250` у Алхимика), **слияние дубликатов (`★1→★5`)**, **переплавка 10 осколков в 1 Руду**, **вечная Тёмная заточка** за `🌑` и ковка вечных `♾️` предметов (включая **7 Ультимативных рецептов с поглощением редких вещей**: 2 клинка, талисман, танковые латы, 2 ульт-щита вплоть до **`🪞 Вечного Монолита Отражения`** и 2H меч с Выносливостью и бронёй).
- **Настраиваемые авто-зелья (HP, MP и баффы)**: независимые пороги и условия (`В бою` / `Всегда`), а также авто-обновление бафф-зелий по истечении с индивидуальным фильтром.

### Классы героя (открываются с Сл.50+)
После достижения 50-й сложности классы можно свободно переключать в любой момент, при этом **заработанные личные бонусы остаются строго за тем классом, который их получил**:
- **🧭 Странник** — сбалансированный базовый класс без ограничений.
- **⚗️ Алхимик** — пассивка **«Золотая реакция»** (`+5%` от текущего количества золота к урону ручной атаки), полный иммунитет к дебафу увеличения цен («Алчность бездны»), заточка до `+250` (`-40%` цены, `1.6x` шанс), `+60%` лечения зелий, `20%` сохранения зелья, `x2` дроп семян и скорость варки, а также защита от каждого 2-го взрыва котла.
- **🧌 Тролль** — каждый удар вешает бесконечный `-1` срез брони (уходит в минус), реген `2.5% Max HP/с` в бою, `+25% Max HP` и `+20%` Силы.
- **🌿 Спирит** — отказывается от экипировки ради `+35%` ко всем статам, `+50%` брони и 4 автономных духов природы (Огонь, Ветер, Лес, Земля) с собственной дрессировкой.
- **🎯 Снайпер Бездны** — `+40%` урона луков/арбалетов, `60%` экономии снарядов, `30%` двойной выстрел, криты игнорируют плоскую броню и усиливаются от Ловкости.
- **🩸 Архимаг Крови** — **2x прирост интеллекта**, **в 3 раза больше Max MP от Инты (`96 MP/ед.` вместо `32`)**, с шансом `10%` при ударе вместо обычной тычки кастует случайное заклинание из быстрого доступа, `+75%` силы чар, `-50%` манакост, `-30%` КД, каст за `8%` текущего HP при нехватке маны и доступ к 7 эксклюзивным заклинаниям крови.
- **🪞 Отражатель** — `0` прямого урона (только лечение, баффы и эксклюзив **`🪩 Зеркальный апофеоз` (`+200%` отражения)**), **`0%` уклонения**, **`20x` прирост Max HP из всех источников** (включая стаки за убийства: `+50` за Вечного титана, `+15` за Хранителя проклятий, `+5` за Смотрителя шахты, `+1` за обычного врага, и **конвертацию Барьера 1:1 в Max HP**), `+30%` прироста HP, `+40%` брони, **до-броневое рассеивание урона** пропорционально `%` отражения (поглощение до `99%`, избыток сверх `99%` усиливает обратный урон) и **моментальный стартовый + секундный тик ауры `5% Max HP + 0.1%` гниения врага**.

### Дерева талантов, сложности, Бестиарий, Шахта, Убежище и эндгейм
- **Обычное древо (50 узлов по `1 ОН`) + 3 пресета автопрокачки (`П1–П3`)** и **3 Боевых комплекта (`К1–К3`)** для мгновенного переключения билдов.
- **Тёмное древо Бездны (37 постоянных узлов)**: включая 5-ю ветку **«Бастион отражения»** и новые узлы на Барьер, пачки врагов, скорость и отражение. За первую победу над Вечным титаном на каждой сложности выдаётся `+2 🌑` (максимум 1 раз за сложность).
- **⏳ Сфера Сброса Сумрака (`0.001%` дроп)**: ультра-редкий вечный предмет, падающий с любого врага с шансом `0.001%` (`0.00001`), который сбрасывает отметки пройденных сложностей (сохраняя максимальную открытую сложность), чтобы снова получать `🌑` за их прохождение.
- **13 локаций, 27 врагов, 📖 Бестиарий, 🏰 Данж 10 волн и 🧭 Авто-маршрут**: ускоренный поиск следующего врага (`0.25с`), **🥋 Полигон тренировок**, прогресс Бестиария по всем 27 врагам (`100 / 1000 / 10000`), чекпоинты Шахты (`10 / 25 / 50`), **🔥 4 Испытания Бездны** при Новом ране и умный Авто-маршрут.
- **🦇 Тёмный магазин**: за каждую победу над Вечным титаном начисляются постоянные `🪙 Монеты Тёмного магазина` (равны пройденной сложности, можно фармить повторно) для покупки дешёвых ультимативных `%`-расходников на текущий ран.
- **Карта деревни, ⛲ Колодец Жадности, Сады и Экспедиции**:
  - **⛲ Колодец Жадности**: пожертвование всего золота рана (КД `15 мин`) ради Руды Бездны, Древних листов, Рероллов, редких семян и случайного благословения рана.
  - **☀️ Светлый сад (Сл.1+)** и **🧭 Экспедиции путников (`15м / 1ч`)**: приманка/дрессировка 6 бессмертных Путников и отправка свободных питомцев на вылазки за наградами.
  - **🌑 Тёмный сад и Зельеварение (Сл.10+)**: 6 редких культур (включая `🌺 Алый лепесток` за 2000 побед над Вечным титаном и `🌟 Первоцвет духов` с шансом `0.03%`), многоступенчатая варка эликсиров со взрывами и полное сохранение прогресса садов между ранами.
- **Экспорт и импорт сохранений**: перенос прогресса между ПК и телефоном через `.txt`-файлы (`HERO_TALE_SAVE_TXT`) или буфер обмена.

## Запуск игры в Godot Engine 4.7

1. Скачайте и установите **Godot Engine 4.7** (стандартная версия, GDScript).
2. В менеджере проектов нажмите **Import** и выберите:
   ```text
   godot_project/project.godot
   ```
3. Откройте проект и нажмите **F5** (главная сцена: `res://scenes/Main.tscn`).
4. Для Android / iOS уже настроены альбомная ориентация (`orientation = 0`), эмуляция тача (`pointing/emulate_touch_from_mouse = true`), рендерер `gl_compatibility` и глобальная тема `mobile_theme.tres`.

## Облачная сборка Android `.apk` через GitHub Actions

В репозитории настроен workflow [`.github/workflows/build-android.yml`](.github/workflows/build-android.yml), который собирает **Release `.apk`** на серверах GitHub (`ubuntu-latest`) с использованием **Godot `4.7.2-stable`** и **Gradle** (без debug-сборки, через `--export-release`).

1. Запушьте изменения в ветку `main`/`master` (или откройте вкладку **Actions → Build Android Release APK (Godot 4.7.2-stable) → Run workflow**).
2. По завершении сборки скачайте артефакт **`hero-tale-android-release-apk`** (`hero-tale-release.apk`). При пуше тега вида `v0.25.0` файл также автоматически прикрепится к GitHub Release.
3. *(Необязательно, для постоянной подписи при обновлениях поверх уже установленной игры)* добавьте в **Settings → Secrets and variables → Actions** три секрета:
   - `ANDROID_KEYSTORE_BASE64` — `base64` вашего `.keystore` файла;
   - `ANDROID_KEYSTORE_ALIAS` — alias ключа;
   - `ANDROID_KEYSTORE_PASSWORD` — пароль keystore и ключа.
   Если секреты не заданы, workflow автоматически создаст временный release-keystore для подписи APK.

## Веб-инспектор и проверка целостности

Для запуска браузерного инспектора кода и прогона автотестов потребуется **Node.js 22+**:

```bash
# Установка зависимостей
npm install

# Запуск веб-инспектора на http://localhost:3000
npm run dev

# Проверка TypeScript и сборка
npm run lint
npm run build

# Запуск тестов целостности Godot-ресурсов и скриптов
npx tsx --test src/utils/godotFiles.test.ts
```
