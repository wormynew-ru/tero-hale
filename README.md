# Hero Tale — 2D Idle RPG (Godot 4.7)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Godot Engine](https://img.shields.io/badge/Godot-4.7-478cbf.svg)](https://godotengine.org/)

Кроссплатформенная 2D Idle RPG в духе **Hero Tale**, созданная на **Godot Engine 4.7** (`GL Compatibility`) с адаптивным горизонтальным интерфейсом (`1280×720`, `canvas_items` + `expand`) для **ПК и мобильных устройств**.

В корне репозитория также находится веб-инспектор исходного кода на React + Vite для быстрого просмотра дерева файлов, сцен и ресурсов `.gd` / `.tscn` / `.tres` прямо в браузере.

---

## Основные механики игры

- **Честный автобой в реальном времени**: без офлайн-прогрессии и кликер-ускорения атак; бой и автосохранение продолжают работать при свёрнутом окне (`PROCESS_MODE_ALWAYS`, `low_processor_mode=false`).
- **Карманный OLED AFK-режим**: снижение FPS до `2 FPS`, чистый чёрный экран `#000000`, блокировка засыпания экрана и кнопка полного отключения рендера.
- **Learn by Doing**: 3 практических навыка мастерства (**Ближний бой**, **Дальний бой**, **Магия**), прокачивающихся напрямую от ударов, выстрелов и потраченной маны.
- **Оружие, дальний бой и дроп-экономика**:
  - Ближний бой и броня: стартовое снаряжение доступно в лавке, а высокоуровневая экипировка и редкие доспехи выпадают только с врагов и боссов.
  - Дальний бой: луки, арбалеты и пачки стрел/болтов (`x50`).
  - Кузня зачарования до `+100` (и до `+250` для Алхимика).
- **Книга заклинаний (20 чар, 3 активных слота)**: прямой урон, мульти-удары, пробитие брони, вампиризм, DoT, баффы, перегрузка *Выжигание души* и 6 запретных заклинаний *Архимага Крови*. Поддержка короткого тапа и удержания (`1 сек`) для автокаста.
- **Классы героя (открываются на Сл.50+)**: *Странник*, *Алхимик*, *Тролль*, *Спирит* (с 4 духами природы), *Снайпер Бездны*, *Архимаг Крови*, *Отражатель*.
- **Бессмертные путники (6 питомцев)**: отдельный слот без HP (включая `🎆 Фейерверк` со станом в начале боя на `5 сек`).
- **Деревья талантов и Престиж**:
  - Обычное древо из **34 узлов** (по `1 ОН` за талант).
  - Тёмное древо Бездны из **26 постоянных узлов** за `🌑 Очки Тьмы`.
  - Система сложностей, случайные проклятия каждые 10 уровней сложности, бонусная локация **Горнило Проклятий (Сл.100+)** и реролл проклятий за жетоны `🎲`.
- **Карта деревни и Убежище (Сл.10+)**: иллюстрированная карта с кликабельными зонами, редкие семена (включая `🌺 Алый лепесток` за 2000 побед над Вечным титаном), Сад и многоступенчатое Зельеварение (Вода → Шаг 1 → Шаг 2 → Шаг 3).

## Запуск игры в Godot Engine 4.7

1. Скачайте и установите **Godot Engine 4.7** (стандартная версия, GDScript).
2. В менеджере проектов нажмите **Import** и выберите файл:
   ```text
   godot_project/project.godot
   ```
3. Откройте проект и нажмите **F5** (главная сцена: `res://scenes/Main.tscn`).
4. Для мобильных сборок (Android / iOS) уже настроены альбомная ориентация (`orientation = 0`), эмуляция тача (`pointing/emulate_touch_from_mouse = true`) и рендерер `gl_compatibility`.

## Веб-инспектор и проверка целостности

Для запуска браузерного инспектора кода и прогона тестов валидации ресурсов Godot потребуется **Node.js 22+**:

```bash
# Установка зависимостей
npm install

# Запуск веб-инспектора на http://localhost:3000
npm run dev

# Проверка TypeScript и сборка
npm run lint
npm run build

# Запуск тестов целостности Godot-ресурсов и скриптов
npx tsx --test src/utils/godotFiles.test.ts
```
